# Локальный API HID Pilot

Отдельный запуск из исходников для внешнего агента. Существующий GUI и алгоритмы
фарма сохранены; одновременно управлять Pico из GUI и API нельзя.
[Команды запуска](../docs/VISION_QUICKSTART.md).

Хост слушает `127.0.0.1`. Дескриптор `--api-file` содержит `protocol: 1`, `url`
и случайный `token`. Все запросы требуют `Authorization: Bearer <token>`.
Дескриптор создаётся без перезаписи существующего файла и удаляется при штатном
закрытии. Токен не передавать в логи/репозиторий.

## Контракт v1

| Метод | Путь | JSON / результат |
|---|---|---|
| GET | `/v1/scripts` | `scripts`: ID доступных API-форков |
| GET | `/v1/status` | session, phase, running, paused, error, окна, epoch, наблюдение |
| POST | `/v1/start` | `{"script_id":"farmer-healer.duo"}` → статус новой сессии |
| POST | `/v1/heartbeat` | `{"session_id":"<32 hex>"}` |
| POST | `/v1/stop` | тот же session_id; запрос немедленного STOP |
| POST | `/v1/pause` | тот же session_id |
| POST | `/v1/resume` | тот же session_id |
| GET | `/v1/frame` | PNG base64, SHA-256, размеры, окно, session/epoch/frame_id, статус |
| POST | `/v1/camera` | session_id, frame_id, target_epoch, direction |

`direction`: `left`, `right`, `up`, `down`. Корневой агент пока использует только
горизонтальные направления. Сила/длительность определены контроллером;
произвольные `dx`, `dy`, клавиши или пути сценариев не принимаются.

Ответы: 200 — успех, 401 — токен, 404 — неизвестный маршрут, 409 — неверный
запрос/недоступная операция, 500 — ошибка capture/ввода. В теле ошибки `error`.
POST ограничен 16 KB. Дополнительные поля запросов запрещены.

`start` запускает подготовку асинхронно. Клиент проверяет `phase/error` и посылает
heartbeat во время подготовки и фарма. Его отсутствие более 5 секунд вызывает STOP.
Возврат `/stop` означает получение команды; завершение подтверждено только когда
`running=false`. `phase=failed` означает ошибку, включая ошибку освобождения ввода.
Следующую сессию нельзя запустить до завершения предыдущего worker.

Времена — Windows `time.monotonic()` на этой машине; API не предназначен для
другого компьютера. Наблюдение может быть неизвестным или устаревшим; `attack_at`
означает отправку команды атаки МА, а не доказанное движение/попадание.
`target_epoch` меняется при запросе выбора цели, а не является ID существа.

Кадр доступен только в активном окне МА, с проверкой PID/геометрии/фокуса,
без паузы и STOP. При занятом вводом контроллере или активном саппорте — 409,
клиент повторяет позже. Изображение BGR кодируется PNG без overlays; в root-клиенте
декодируется в RGB. Полноразмерные кадры передаются по запросу, не как видеопоток.

## Камера и ввод

Ускоренная камера требует HID_PILOT_V7: шаг ×20 (6 → 120), один импульс на запрос.
V5 отклоняет MOVE при зажатой ПКМ; V6 допускает лишь прежний малый шаг. Статус содержит
`camera_supported`: `null` до подключения, затем boolean. Несовместимый протокол
отклоняется до нажатия ПКМ. Фарм без камеры остаётся совместимым с V5.

Камера проверяет последний выданный кадр, session/epoch, возраст кадра
до 0,9 с, наблюдения до 1 с, запрос атаки до 20 с, положительное HP цели, отсутствие
критического состояния и активность МА. До 32 запросов на выбор цели; повтор кадра
отклоняется. Проверки повторяются во время поворота. ПКМ отпускается и при ошибке.
Операция не вклинивается между key-down и key-up фарма.
Для камеры допускаются типы `monster` и `unknown`: ожидание OCR имени не должно
блокировать визуальный поиск. Известные игроки/NPC исключены; решения об атаке
и их проверки не меняются. Ожидание lock ввода до 0,2 с. Ошибка 409 содержит
конкретную причину отказа камеры.

Сценарии принимаются только из `--scripts` с маркером
`# agent-input-policy: clicks-only`. Клавиши и клики прежнего фарма сохраняются;
отдельные `move` и `recover_view` от фарма блокируются адаптером. Для клика
разрешено наведение. Камера проходит через тот же ActionController и Pico.
Независимого второго контроллера или fallback на SendInput нет.

Глобальный hard-stop `\` обязателен до старта. Закрытие API вызывает STOP.
Работа с реальной игрой ещё требует совместной проверки; это экспериментальный
интерфейс v1. [Где применяется мышь](../docs/MOUSE_USAGE.md).
