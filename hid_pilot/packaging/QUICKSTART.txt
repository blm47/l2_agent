HID Pilot 0.3.1 — Windows 10/11 x64

Запуск:
1. Скопируйте HID_Pilot.exe и нужную папку extensions рядом с ним. Python и интернет не нужны.
   Альтернативный вариант: распакуйте ВСЮ папку HID_Pilot_Portable из ZIP и запустите её EXE.
2. Pico контроллер → Прошивка / сброс / проверка.

Новый Pico / Pico W (RP2040):
1. Подключите USB data cable, удерживая BOOTSEL. Появится диск RPI-RP2.
2. Выберите диск и точную модель платы. Нажмите «Установить CircuitPython».
3. Дождитесь диска CIRCUITPY и нажмите «Обновить платы и COM-порты».
4. Выберите CIRCUITPY и нажмите «Установить / обновить HID Pilot».
5. Безопасно извлеките CIRCUITPY в Windows, переподключите USB без BOOTSEL.
6. Нажмите «Проверить прошивку». Нужны SHA256 файлов, HELLO HID_PILOT_V3 и STATUS DISARMED.
   CDC data port выбирается в главном окне после успешной проверки.

Существующая HID-плата:
Обычно достаточно шагов 4–6. Перед записью автоматически сохраняется копия файлов CIRCUITPY.
Для смены CircuitPython сначала сохраните копию, затем подключите плату с BOOTSEL.

Полный сброс:
Сначала сохраните нужные файлы CIRCUITPY. В режиме BOOTSEL отметьте подтверждение удаления
и нажмите «Полный сброс памяти». Стирается вся flash: CircuitPython, файлы и NVM.
После сброса повторите установку CircuitPython и HID Pilot. Копия файлов не является образом NVM.

Сценарии и клики:
Выберите окно игры. Вкладка «Общее» — клавиши и ЛКМ/ПКМ в текущей точке курсора.
Меню Файл → Открыть папку примеров скриптов. Откройте и сохраните сценарий перед калибровкой.
Профили HP/MP/пати нужно создать на новом компьютере для его окна, DPI и размера.
START активирует окно; потеря фокуса включает паузу. STOP и глобальная клавиша \ останавливают ввод.
Во время прошивки сценарии не запускаются. Проверка прошивки не отправляет клавиши или клики.

Файлы приложения: %LOCALAPPDATA%\HIDPilot
Логи: logs\hid-pilot.log
Резервные копии Pico: pico-backups
Примеры сценариев: scripts
Расширения хила и фарма: extensions рядом с EXE, отдельно от компилируемой программы.
Без расширений доступны общие клавиши и базовые команды DSL.
Для обновления алгоритма замените соответствующие .py в extensions/hid_pilot и перезапустите EXE.

Pico 2 / Pico 2 W и сторонние платы в этой сборке не поддерживаются.
Если UF2 записан, но плата не появилась: переподключите USB, проверьте data cable и BOOTSEL.
Если используется обычный CDC console port вместо data port, проверка не пройдёт; выберите другой COM.

Самопроверка сборки без платы:
HID_Pilot.exe --self-test --report self-test.json
