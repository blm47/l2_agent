# HID_PILOT_V10: рывок с обслуживанием heartbeat и STOP

CAMERA возвращает MOVING и выполняет по одному report (до 24 единиц) за tick.
CAMERA_STATUS возвращает MOVING/DONE. Основной цикл продолжает принимать HB/STOP;
Рывок завершается только после DONE. Контроллер удерживает ПКМ до 1000 мс,
проверяет окончание с бюджетом 800 мс и всегда освобождает кнопки.
Прежний watchdog без heartbeat 350 мс сохранён. После DONE и отпускания ПКМ
root запрашивает новый кадр и ищет кружки. Старый блокирующий V9 не подходит.

# HID_PILOT_V9: сильный рывок камеры

V9 добавляет `CAMERA dx dy`: одна ненулевая ось, модуль до 900, только armed
при удержании ПКМ. После настройки пользователем смещение выполняется HID reports
до 24 вместо 120: номинальная скорость снижена в 5 раз при прежнем USB polling.
Поисковый рывок уменьшен с 900 до 300 единиц, без COM round trips.
Deadline ПКМ и watchdog проверяются между reports. MOVE/WHEEL не изменены.
Обновление платы выполняется только явно пользователем.

# HID_PILOT_V8: масштаб камеры

V8 добавляет `WHEEL n`, n от -4 до 4, кроме 0; только armed без удержаний.
Команда создаёт одиночный mouse wheel report, не удерживает кнопки.
Неправильная команда снимает допуск. Возможности V7 сохранены.
Установлена на Pico UID 5303284718697D9C 2026-11-03, COM4; SHA256/HELLO/STATUS проверены.

# HID_PILOT_V7: ускорение камеры

V7 допускает MOVE до ±120 на ось только во время ПКМ. Обычный MOVE сохраняет
предел ±16, deadline удержания и heartbeat не продлеваются. Это обеспечивает
шаг камеры ×20: 6 → 120. Установлена на Pico UID 5303284718697D9C 2026-11-03,
COM4; файлы, HELLO V7 и STATUS DISARMED проверены. После теста камеры ПКМ отпущена.

# HID_PILOT_V6: движение с ПКМ для камеры

V6 сохраняет команды V5. MOVE разрешён во время удержания только правой кнопки
мыши; report сохраняет бит ПКМ. Предел смещения остаётся ±16 на ось.
MOVE не продлевает deadline кнопки и heartbeat. STOP, RELEASE, disconnect,
истечение удержания и watchdog отпускают ПКМ. Во время KEY/CHORD/ЛКМ MOVE
по-прежнему отклоняется. HELLO возвращает HID_PILOT_V6.

API проверяет эту возможность до ввода камеры. V5 поддерживает фарм и обычное
наведение, но не поворот с зажатой ПКМ. Обновление платы выполняет пользователь
через обслуживание Pico; автоматической записи прошивки нет.

# Клавиатура HID_PILOT_V4

V4 добавляет `CHORD CTRL+A ms` и `CHORD SHIFT+буква ms` для чата.
Другие сочетания отклоняются. KEY допускает 1–3000 мс, CHORD/BUTTON — 1–1000 мс.
Heartbeat и deadline освобождают весь report, включая модификаторы.
HELLO исходников возвращает HID_PILOT_V4. На плату обновление автоматически не записывается.

Прошивка поддерживает стандартную клавиатуру на 104 клавиши, кроме backslash `\`.
Он зарезервирован для физического hard-stop и отвергается даже прямой командой
в COM-порт. ISO-варианты backslash также отсутствуют в таблице. Каждая команда
KEY нажимает одну физическую клавишу на 1–3000 мс. Сочетания принимаются только
отдельной командой CHORD с приведённым выше allowlist.

| Группа | Имена в сценарии |
| --- | --- |
| Буквы и цифры | `A`–`Z`, `0`–`9` |
| Функциональные | `F1`–`F12` |
| Основные | `ENTER`, `ESC`, `BACKSPACE`, `TAB`, `SPACE`, `CAPSLOCK` |
| Пунктуация | `-`, `=`, `[`, `]`, `;`, `APOSTROPHE`, `GRAVE`, `,`, `.`, `/` |
| Навигация | `INSERT`, `DELETE`, `HOME`, `END`, `PAGEUP`, `PAGEDOWN`, `UP`, `DOWN`, `LEFT`, `RIGHT` |
| Служебные | `PRINTSCREEN`, `SCROLLLOCK`, `PAUSE`, `MENU` |
| NumPad | `NUM0`–`NUM9`, `NUMLOCK`, `NUMDIVIDE`, `NUMMULTIPLY`, `NUMSUBTRACT`, `NUMADD`, `NUMENTER`, `NUMDECIMAL` |
| Модификаторы | `LCTRL`, `RCTRL`, `LSHIFT`, `RSHIFT`, `LALT`, `RALT`, `LWIN`, `RWIN` |
| Псевдонимы левых модификаторов | `CTRL`, `SHIFT`, `ALT`, `WIN` |

Например: `key NUM7 100`, `key ENTER 100`, `key RSHIFT 100`.
Модификаторы формируют отдельные биты USB-отчёта и полностью освобождаются
при deadline, RELEASE, STOP и потере heartbeat. Следующая команда не сохраняет
предыдущий модификатор. Раскладка ОС определяет символы: `A` — физическая клавиша,
а не команда переключить раскладку или напечатать латинскую букву.

F9 доступна для игры; регистрация горячей клавиши PAUSE/RESUME удалена.
Ручная пауза доступна только мышью в интерфейсе. Fn и мультимедийные кнопки
не входят в стандартные 104 клавиши: Fn обычно обрабатывается самой клавиатурой,
а multimedia требует отдельного Consumer Control HID-интерфейса.

HELLO возвращает `HID_PILOT_V4`. Приложение сохраняет поддержку старых протоколов,
но отклоняет неподдерживаемые ими клавиши до отправки. Хилер работает с V2 и V3.
2026-10-04 по явному запросу пользователя V3 установлена на Pico
UID 5303284718697D9C, COM4. Проверены SHA256 файла, HELLO V3 и STATUS DISARMED.

Источник кодов: [USB-IF HID Usage Tables, Keyboard/Keypad Page 0x07](https://www.usb.org/sites/default/files/hut1_21_0.pdf),
проверено 2026-10-04. Таблица на плате автономна; тест сверяет её с приложением.
# HID_PILOT_V5: резервный ALT+TAB

V5 сохраняет обычные команды V4 и добавляет `SWITCH ALT+TAB 80`.
Команда принимается только в disarmed-состоянии, удерживает ALT+TAB
не больше 80 мс и освобождает HID по deadline. Другие сочетания и длительности
в SWITCH отвергаются. CHORD ALT+TAB по-прежнему запрещён.
Команду использует только ActionController при резервном переключении
проверенной пары окон. При попадании в другое приложение сессия останавливается.
HELLO возвращает HID_PILOT_V5; ПК отдельно включает эту возможность,
оставляя совместимый набор обычных команд V4 для остальных сценариев.
