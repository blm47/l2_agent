# Панель цели и статистика мобов

В автопоиске HP / MP / CP / цели / пати откройте «Панель цели: игрок / NPC / монстр и красный череп…».
На кадре с выбранным монстром выделите всю панель с именем и HP, затем место нижней полоски HP.
Для дополнительного признака смерти выделите красный череп на кадре с мёртвым монстром.
Сохраните результат в `farm-bars.json`. Настройки сохраняются при повторном открытии калибровки.

OCR читает произвольное имя монстра. Панель с именем и HP считается монстром;
отсутствие полоски в настроенной области — признаком NPC. Неразборчивые цифры при
видимой полоске не превращают монстра в NPC. Для игрока сохраняются ник, класс и клан.
Неоднозначное наблюдение остаётся неизвестным. При необходимости можно указать известные имена NPC.
Нулевой HP подтверждает смерть; шаблон красного черепа служит дополнительным признаком.
Положительный HP имеет приоритет перед черепом.

Раз в минуту общий логгер выводит количество смертей мобов за интервал, общее количество,
время сессии и счётчики по именам. Работает в наблюдении пати, хиле, режиме париков и фарме.
Счётчик сбрасывается при начале новой сессии наблюдения или сценария.

Учитывается наблюдаемый переход живого монстра в мёртвого с подтверждением на двух кадрах.
Повторные кадры трупа, уже мёртвая первая цель, исчезновение панели, игроки и NPC не увеличивают счётчик.
После смерти нужны два живых кадра для повторного учёта монстра с тем же именем.
В сводке показываются десять самых частых имён; хранится до 256 видов, остальные объединяются в «прочие».

Это статистика смертей выбранных целей: панель не позволяет установить, кто нанёс последний удар.
Смерти вне таргета или между кадрами могут быть пропущены. Проверка в реальной игре необходима
после калибровки под размер окна и DPI.

Новые поля профиля необязательны; старые профили сохраняют совместимость.
Изменения включают основной код приложения, поэтому для готового EXE потребуется отдельный релиз.
