# HID Pilot

Последнее уточнение пользователя от 2026-10-13: сильный урон сначала лечить
массовыми скиллами. Одиночный хил участника разрешать только если два интервала
сильного падения HP наблюдаются после завершения массового каста. Урон до него
и один лишь прирост HP не разрешают выделение цели для одиночного лечения.
После подтверждения точечный хил доступен также при HP выше 50%.
Признак продолжающегося сильного урона удерживается кратковременно
для устойчивого наведения; пропуск данных, новая разметка, смерть или полное HP
его сбрасывают. Аварийный баланс и защита Разрушителя сохраняются.
Обычный group даёт бафф на 15 секунд: до окончания расчётного каста +15 секунд
повтор не отправлять; для повторного массового лечения использовать mass_major.
Таймер хранить вместе с откатами и восстанавливать после перезапуска.

Последнее правило от 2026-10-12: Invocation — MP <80% и минимум 30 секунд
непрерывного наблюдения без урона по HP/CP всей пати. Пропуски данных
сбрасывают ожидание; прежнее исключение для MP <20% отменено.
В массовом лечении сначала обычный group (F6), затем mass_major (F2).
Уточнение: group открывает лечение, а не вытесняет остальные скиллы.
После него баланс, Пробел, одиночные хилы, avatar и массовый мажор выбираются
по HP, урону и откатам, в том числе в COLLECT. При HP <=35% или сильном уроне
после первого масс-хила целевое спасение не требует видимого прироста HP.
Защита Разрушителя остаётся обязательной.

Правило пользователя от 2026-10-08 для всех хилерских расширений:
при иконке скилла Разрушителя рядом с участником запрещён Balance Life,
включая аварийный баланс. Эталон: extensions/assets/destroyer.png.
Целевым хилом итоговое HP участника с этой иконкой нельзя повышать выше 20%.
Пока точный эффект скилла не измерен, он исключается из одиночного хила.
Уточнение пользователя: group/mass_major/avatar и Пробел разрешены для
лечения остальных, даже если затронут Разрушителя и поднимут его HP выше 20%.
Баланс остаётся запрещён, включая аварийный.

Уточнение пользователя от 2026-10-12 для режима париков: массовый хил разрешён
также при сборе. По последнему уточнению следование ведущему включено во всех
фазах, включая сбор, между кастами и более приоритетным лечением.
Без наблюдаемого эффекта массового хила по участнику не выделять его
для одиночного лечения; это не отключает обычное следование ведущему.
Исключение: если после массового хила HP ниже 50% и сильный урон подтверждён
двумя интервалами, разрешено выделение для срочного одиночного хила даже без
прироста HP. Защита Разрушителя сохраняется. При HP <=35% и балансе в откате
используется хил вокруг себя на SPACE: каст 0,4 секунды, откат 25 секунды.
После завершения каждого лечебного каста нажать случайную W/A/S/D на 1000 мс.
Это изменение отменяет прежний запрет массового лечения во время сбора.

Самостоятельный проект, созданный по запросу пользователя в feature/hid-pilot.
Родительские ограничения milestone L2 Agent к этому приложению не применяются.
Цель: текстовые макросы для выбранного окна, наблюдение через CV, весь ввод через Pico HID.
Нет зависимости от l2_agent, LLM, игрового протокола или Adrenaline.
Только ActionController отправляет команды ввода. Запрещён fallback на SendInput.
Проверять фокус, PID, геометрию, границы клика и hard-stop перед вводом.
Прошивка имеет собственные deadlines и watchdog. Не прошивать плату автоматически.
Сохранять русские комментарии, единый logger и отдельные строки тройных кавычек.

Доработки и тестирование функционала выполняются без пересборки поставки.
Собирать EXE, релизные архивы и обновлять dist разрешено только отдельным релизом
по прямому запросу пользователя. Обычный запрос на изменение или проверку
функционала не разрешает запуск сборки поставки.

Стан на хилере может длиться 3–7 секунд и мешать применению скиллов. Отсутствие
эффекта нажатия не подтверждает ни стан, ни недоступность цели: эффект может
скрываться входящим уроном. До реализации распознавания дебаффов не объявлять
стан достоверным и не исключать всю пати из лечения только по отсутствию эффекта.
