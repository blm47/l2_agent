# Форки дуо для API корневого агента

Три `.pilot` скопированы из `hid_pilot/extensions/scripts` с сохранением всех
настроек. Комментарий `agent-input-policy: clicks-only` разрешает API-хосту
распознать предназначенные ему сценарии.

| ID API | Исходный файл |
|---|---|
| `farmer-healer.duo` | `farmer-healer.duo.pilot` |
| `farmer-healer_SINGL.duo` | `farmer-healer_SINGL.duo.pilot` |
| `farmer-healer_wAOE.duo` | `farmer-healer_wAOE.duo.pilot` |

Профили окон задаются отдельно через `--profiles`; они должны соответствовать
текущим окнам МА/саппорта. Копии не требуют изменения оригинальных сценариев.

Политику движений применяет API-адаптер, а не комментарий в обычном GUI Pilot.
Клики с необходимым наведением остаются. Самостоятельное движение курсора из
фарма запрещено, экспериментальная камера вызывается корневым агентом отдельно.
