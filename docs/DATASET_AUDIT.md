Просмотрены обзорные листы всех 23 кадров; два кадра с пропущенным персонажем
дополнительно просмотрены крупно. Это первичный аудит, не подтверждение правильности
каждой из 464 рамок. Исходные пользовательские метки не изменялись.

Дополнительно проверить:

- `04f4f58489834f79bc1a043c28dd46ab`: область персонажа перекрыта окнами/эффектом;
  определить, осталась ли различимая часть, которую нужно размечать.
- `69718d1d5fff4a9ca6f1fcf367825572`: дальние видимые существа над рамкой №3
  требуют проверки полноты разметки.
- Рамки существ часто включают надпись над головой и большой участок фона.
  Для дальнейшей разметки принять единое правило: рамка по видимому телу объекта,
  текст над головой отдельно не включать. Ранее сделанные рамки проверить на согласованность.
- `ui_window` включает разные панели, карту и тонкую нижнюю строку; панели HP
  и цели обычно пропущены. Нужно явно определить, какие элементы входят в этот класс,
  либо исключить класс из отдельного экспериментального обучения. Молча не менять метки.

## Ограничения первого обучения

По запросу пользователя сохранено разделение train/val внутри тех же локаций/сессий.
Метрики на этих шести val кадрах не подтверждают перенос на новые сцены.
Для npc, corpse и loot слишком мало разнообразных примеров для вывода о надёжности.
203 из 464 рамок относятся к интерфейсу, поэтому общая метрика может скрывать
плохое распознавание игровых объектов: смотреть показатели отдельно по классам.

Перед пробным обучением исправить подтверждённые пропуски и повторить экспорт
в новый каталог. Затем допустим технический пробный запуск; приёмка M1 этим
не закрывается. Обучение в рамках этого аудита не запускалось.
