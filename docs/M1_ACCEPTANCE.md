# Приёмка М1 — Perception

Статус: принята пользователем 2026-09-28 с перечисленными ниже ограничениями.
Пользователь подтвердил пункты проверки HP/MP, актуальности WorldState и overlays,
принял стабильность с переносом расследования паузы GUI в TODO и согласовал
закрытие вехи. Переход к реализации М2 в этой итерации не выполнялся.

## Основания

| Критерий ROADMAP | Подтверждение |
| --- | --- |
| Проверка HP/MP на размеченных скриншотах | Ранее проверены четыре реальные полные полосы с ошибкой менее 2 процентных пунктов; частичные и неоднозначные состояния проверялись синтетически. Пользователь явно принял пункт проверки полос. Новых количественных измерений при приёмке не было. |
| Непрерывное обновление WorldState | Пользователь принял пункт стабильности; пауза replay отложена отдельно. |
| Unknown/низкая уверенность вместо выдуманных значений | Контракты и тесты отказов/устаревания; пользователь подтвердил пункт сброса результатов при смене окна, resize, сворачивании, пропадании кадра и смене цели. |
| Overlay показывает результаты восприятия | Пользователь подтвердил пункт проверки overlays и полноты превью в игре. |

Реализованы ROI, парсер полос, OCR abstraction и чтение имени цели, формат
датасета и редактор, начальный ONNX-детектор, WorldState и overlays.
Скрипт сбора сохраняет предразметку в UUID-папках; экспорт в обучение требует
ручного подтверждения статуса reviewed.

## Ограничения, сохраняющиеся после приёмки

- В replay наблюдался event-loop gap около 9,6 секунды. Пользователь его
  не заметил в живой работе и явно отложил расследование; причина не установлена.
- OCR имени цели нестабилен на меняющемся фоне, улучшение ранее отложено.
- Качество YOLO по мобам/NPC остаётся ограниченным; дополнительные кадры
  и дообучение отложены. Начальный inference выполняется на CPU.
- Реальный размеченный набор полос пока ограничен; принятие пользователем
  не означает появления расширенного набора или новых измерений точности.
- Приёмка М1 не разрешает автономный ввод и не является приёмкой М2/М3.
