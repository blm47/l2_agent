# Классы детектора — схема 2

Список расширен до 23 классов. ID 0–5 сохранены для совместимости с исходной
разметкой; новые ID добавлены в конец. Имена `system_chat` и `skills_panel`
нормализованы из пользовательского списка. Порядок задаёт `DetectorClass` в dataset.py.

| ID | Класс | Что обводить |
|---:|---|---|
| 0 | mob | Живой моб, не выбранный целью |
| 1 | npc | NPC |
| 2 | player | В новой разметке — собственный персонаж; старые метки проверить |
| 3 | corpse | Тело погибшего существа или персонажа |
| 4 | loot | Предмет на земле |
| 5 | ui_window | Совместимость со старой разметкой; уточнять до класса панели, если он есть |
| 6 | mob_selected | Живой моб, выбранный текущей целью; не сама панель цели |
| 7 | player_other | Другой игрок |
| 8 | minimap | Миникарта |
| 9 | hotbar | Панель ячеек быстрых действий и умений |
| 10 | chat | Окно общения |
| 11 | system_chat | Окно системных сообщений |
| 12 | skills_panel | Окно списка умений |
| 13 | tool_bar | Панель кнопок открытия окон интерфейса, отдельно от hotbar |
| 14 | character_status_panel | Окно характеристик персонажа |
| 15 | inventory | Окно инвентаря |
| 16 | actions_panel | Окно действий |
| 17 | quests_panel | Окно заданий |
| 18 | clan_panel | Окно клана |
| 19 | general_menu_panel | Окно общего меню |
| 20 | current_exp_panel | Область текущего опыта/полосы опыта |
| 21 | current_adena_panel | Область отображения текущей адены |
| 22 | current_time_panel | Область отображения текущего времени |

Не ставьте одновременно mob и mob_selected на одно тело. Для mob_selected редактор
автоматически записывает selected=true. Этот класс пригоден только когда выбор
различим по изображению; флаг не является доказательством распознавания моделью.
Не размечайте один элемент одновременно как ui_window и более конкретную панель.
Отдельный индикатор внутри большого окна может иметь собственную рамку — это другой
объект. Для существ рамка охватывает видимое тело без надписи над головой;
для панелей — видимые границы элемента.

## Уточнение старых кадров

Откройте sample.json в редакторе. Выберите рамку в списке, затем новый класс
и «Применить класс к выбранной рамке». Геометрия сохраняется. Добавьте недостающие
рамки, подтвердите полноту и сохраните. Отмена не меняет файл.

Старые файлы без taxonomy_version читаются как схема 1. Новые кадры и явно
пересохранённая разметка получают taxonomy_version=2. Экспорт схемы 2 отклоняет
кадры, которые ещё не проверены по новой схеме; автоматической переклассификации нет.
Существующие экспорты и веса baseline остаются шестиклассовыми. После уточнения
разметки сделайте новый экспорт и отдельное обучение. Новый список классов сам
по себе не добавляет способности существующим весам.
