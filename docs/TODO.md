## HID Pilot — видеобуфер фарма через OBS

Добавлено 2026-10-24 по запросу пользователя. Статус: код smoke-интеграции
реализован, отдельные профиль и коллекция OBS настроены; полный пяти­минутный
smoke и измерения нагрузки ожидают проверки.
Самостоятельная доработка HID Pilot, без изменения milestone L2 Agent.
Настройка и ограничения: [RECORDING.md](../hid_pilot/RECORDING.md).

Цель первой smoke-интеграции: галочка **«Вести запись» рядом со START**;
только по смерти персонажа сохраняется ролик примерно
**4 минуты 55 секунд до смерти + 5 секунд после** (уточнение пользователя
2026-10-24). STOP, остальные причины завершения и закрытие Pilot
сразу останавливают буфер без сохранения, включая отмену ожидающего хвоста смерти.
Исключение от 2026-10-25: штатный конец добивания после смерти саппорта
сохраняет уже запрошенный ролик смерти, даже если добивание заняло меньше 5 секунд.
Старое видео автоматически вытесняется,
многочасовая сессия не увеличивает временный буфер.

Для первого варианта использовать установленный OBS и Replay Buffer через
obs-websocket. В OBS сжатый буфер находится в RAM, итоговые ролики — на SSD.
Предварительные настройки: выбранный монитор целиком, родное разрешение,
15 FPS, H.264 NVENC с быстрым preset, 8 Мбит/с, без звука, 300 секунд истории,
лимит буфера 512 МБ. При таком битрейте пять минут видео — около 300 МБ;
читаемость цифр проверить в реальной записи. Лимит временного буфера и объём
сохранённых роликов учитывать отдельно.

  Для smoke OBS запускается пользователем. Проверить доступность локального
  obs-websocket и настроек Replay Buffer; пароль не писать в логи.
- [x] Добавить галочку «Вести запись» рядом со START, по умолчанию выключенную,
