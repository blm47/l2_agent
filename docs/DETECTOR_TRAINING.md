# Первое обучение детектора

Обучение выполняется отдельно от GUI в `.venv-train` (Python 3.12).
Тяжёлые зависимости не включены в основной runtime агента.
Первый эксперимент: предобученный YOLOv8n, все шесть классов, FP32,
960 px, batch 2, workers 0, без RAM cache, до 60 эпох, patience 15.
Горизонтальное отражение отключено, поскольку кадры содержат интерфейс и текст.
Параметры являются начальной экспериментальной конфигурацией, не результатом поиска.

```powershell
uv venv .venv-train --python .\.venv\Scripts\python.exe
uv pip install --python .venv-train/Scripts/python.exe torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu118
uv pip install --python .venv-train/Scripts/python.exe ultralytics==8.3.200
.\.venv-train\Scripts\python.exe scripts/train_detector.py --run artifacts/training/m1-yolov8n-20260926
```

Скрипт проверяет CUDA вычислением, сохраняет копию датасета, версии окружения,
параметры, best/last weights, поклассовые метрики и предсказания на val.
Каталог запуска должен быть новым. Существующие результаты не перезаписываются.
Компоненты разметки/экспорта в основном `.venv` проверены отдельно до запуска.

Источники установки и API (проверены 2026-09-26):
[PyTorch previous versions](https://pytorch.org/get-started/previous-versions/),
[Ultralytics YOLOv8](https://docs.ultralytics.com/models/yolov8/).

Шесть val кадров из тех же сессий — диагностическая выборка; её метрики не
подтверждают качество в новых сценах. Редкие классы проверять отдельно.

## Результат 2026-09-26

Запуск `artifacts/training/m1-yolov8n-20260926` завершил 60 эпох.
В датасете после исправлений 23 кадра, 466 рамок; 17 train / 6 val.
Время по results.csv: 258 секунд на 60 эпох, без установки окружения и финальной проверки.
Веса: `fit/weights/best.pt` (6 271 146 байт). Предсказания при confidence 0.25:
`predictions/`, обзор — `predictions/overview.jpg`.

| Класс | AP@50 | AP@50–95 |
|---|---:|---:|
| mob | 0.199 | 0.057 |
| npc | 0.000 | 0.000 |
| player | 0.264 | 0.060 |
| corpse | 0.000 | 0.000 |
| loot | 0.000 | 0.000 |
| ui_window | 0.799 | 0.682 |

Средние mAP@50=0.210, mAP@50–95=0.133. Значение precision=1, которое библиотека
показывает для классов с нулевым recall/AP, не означает, что они распознаются.
Просмотр всех шести предсказаний подтверждает: панели интерфейса распознаются
заметно лучше существ; игроки и NPC путаются с мобами, часть мобов пропускается.
Модель не готова для выбора боевой цели.

PyTorch peak allocated CUDA: 1674 MiB (не общий VRAM процесса).
Выборочный мониторинг процесса и дочерних процессов: peak RSS около 1533 MiB;
мониторинг начат после старта, это не точная верхняя граница памяти всего запуска.
Val inference около 17 ms/изображение, postprocess около 11 ms; только 6 кадров,
это не live benchmark агента.

Сохранены `summary.json`, `environment.json`, `requirements.freeze.txt`,
`pretrained.json` с SHA-256, `fit/args.yaml`, `fit/results.csv`, копия датасета
и тренировочного скрипта. Обучение проверено реальным GPU-прогоном;
общий набор тестов не запускался. PowerShell отобразил stderr логгера как
NativeCommandError; traceback обучения нет, итоговый лог, веса, validation и все
шесть файлов предсказаний подтверждают завершение.
