## Результат обучения

Итоговый запуск успешно завершён (exit code 0): 60 эпох, 593.9 секунды обучения.
YOLOv8n с исходными pretrained весами, 23 выходных класса, 960 px, batch 2, FP32.
Лучшие веса сохранены в `fit/weights/best.pt`; финальная проверка использует их.
