# Сетевой источник WorldState

Решение пользователя от 2026-10-03: CV или собственное пассивное сетевое ядро.
Клиент LU4 сейчас работает локально. Для Parsec capture должен работать на
удалённой игровой машине: видеопоток не содержит игровой TCP-сессии.

## Что работает

`l2-agent --world-source cv` сохраняет прежнюю обработку изображения.
`l2-agent --world-source network` выбирает экспериментальный источник;
GUI также позволяет переключаться. Смена приостанавливает ввод и очищает
снимок. Пока декодер отсутствует, состояние недоступно; CV не подмешивается.

Модуль `python -m l2_agent.network_capture` собирает одну явно заданную
TCP-сессию в pcapng. Требуется отдельно установленный Wireshark/dumpcap с
рабочим capture-драйвером. Длительность по умолчанию 30 секунд, максимум 300;
размер ограничен 16 MiB (порог dumpcap), буфер 4 MiB. Promiscuous mode выключен.
Существующий файл не перезаписывается. Payload не выводится в лог.

Список интерфейсов: `dumpcap -D`. Адреса и порты нужно взять из текущего
соединения процесса LU4, например через `Get-NetTCPConnection -OwningProcess <PID>`.
Не следует угадывать стандартный порт Lineage 2 или захватывать весь интерфейс.

Пример с условными адресами (заменить все параметры своей сессией):

```powershell
python -m l2_agent.network_capture --interface 1 --client-ip 192.0.2.10 --client-port 50000 --server-ip 198.51.100.20 --server-port 7777 --duration 30 --output artifacts/network/session.pcapng
```

Справочник опций: https://www.wireshark.org/docs/man-pages/dumpcap.html
(проверен 2026-10-03). Дампы исключены из Git; они могут содержать приватные
данные. Сбор запускается отдельно и не включается выбором источника в GUI.

## Что предстоит проверить

1. Установить доступность capture-драйвера и определить TCP-сессию LU4.
2. Собрать короткую запись уже вошедшего в мир персонажа, сопоставить её
   с наблюдаемыми изменениями HP и выбранной цели.
3. Установить формат framing, версию протокола и наличие шифрования.
   Не считать отдельный TCP-пакет игровым сообщением. Не угадывать opcode.
4. Реализовать ограниченный TCP reassembly с retransmission, пропусками,
   переподключениями и независимыми направлениями. При пробеле сбрасывать
   достоверность, а не публиковать старое состояние как свежее.
5. Добавить подтверждённый декодер и тесты на обезличенных fixtures.
   Если формат недоступен без вмешательства в клиент, источник остаётся
   недоступным; обход защиты не входит в работу.
6. Расширить контракт WorldState метаданными сетевого источника/сессии,
   отдельной свежестью полей и игровыми координатами. Не выдавать сетевые
   координаты за экранные bounding boxes и сетевой счётчик за frame_id.
7. Подключить к GUI/advisory; проверить TTL, disconnect, смену окна и источника.

Live capture, декодирование, бафы и списки сущностей пока не проверены и не
реализованы. Этот этап не закрывает M2 и не включает автономное управление.
