# Где используется мышь и что изменено для API-фарма

Проверены три исходных файла:

- `hid_pilot/extensions/scripts/farmer-healer.duo.pilot`;
- `hid_pilot/extensions/scripts/farmer-healer_SINGL.duo.pilot`;
- `hid_pilot/extensions/scripts/farmer-healer_wAOE.duo.pilot`.

Это файлы настроек, а не три разных реализации алгоритма. В них нет команд
`move`, `click` и вращения камеры. Все используют `DuoFarmer -> MeleeFarmer -> Farmer`.
В текущих алгоритмах дуо/мили нет прямых вызовов движения курсора. `search_movement`
управляет **WASD**, а `humanize` в этих сценариях в том числе меняет длительности
нажатий/пауз. Эти настройки сохранены: отключать их ради удаления mouse move
означало бы менять поведение клавиатурного фарма.

## Достижимый из дуо путь

| Место | Назначение | API-форк |
|---|---|---|
| `controller.py::target_by_name` | После ввода `/target` — короткий ПКМ в текущей точке внутри игры; если курсор снаружи — наведение в центр и ПКМ | Сохранено как клик |
| `controller.py::click` | Наведение в заданную нормализованную точку, проверка точности/границ, затем кнопка | Сохранено; движение разрешено только внутри операции клика |
| `controller.py::click_current` | Нажатие в текущей проверенной точке | Сохранено |

Если курсор после запуска остался над терминалом, ветка `/target` может двигать
его в центр именно для клика. Это единственный найденный путь наведения курсора
из текущего дуо-алгоритма. Косметического возврата курсора, случайного хождения
мышью и фонового вращения камеры в этих трёх алгоритмах не найдено.

## Остальные возможности самостоятельного HID Pilot

Они не удалены из продукта и не входят в рассматриваемые дуо-форки:

| Место | Использование |
|---|---|
| `controller.py::move`, `_move_to`, `_feedback_move` | Общие механизмы наведения через относительные HID MOVE |
| `controller.py::_timed_return` | Косметический возврат курсора по траектории с ограничением времени |
| `controller.py::recover_view` | Восстановление вида: WASD, центрирование курсора, три поворота с ПКМ |
| `runner.py`, операция `move` | Явная команда движения в обычном языке `.pilot` |
| `runner.py`, операция `click` | Наведение к координатам или свежему find/color и клик |
| `extensions/hid_pilot/healer_runtime.py` | Клики пати, случайные перемещения около центра, восстановление вида |
| `extensions/hid_pilot/train_runtime.py` | Координатные клики по целям/пати |
| `extensions/hid_pilot/farm_ee.py` | Выбор участника пати координатным кликом |

Пути выше указаны относительно `hid_pilot`.

## API-форки

Копии лежат в `agent_scripts/duo`. Их распарсенные настройки полностью равны
оригиналам; добавлен маркер политики и сведения об источнике. Оригинальные
файлы и методы базового `ActionController` не меняются.

Только API-путь использует `ApiActionController`: самостоятельные `move` и
`recover_view` фарма запрещены. Для координатного клика разрешено ограниченное
наведение. Камера — отдельная высокоуровневая API-операция через тот же контроллер
и тот же Pico. Она сериализуется с вводом фарма и не использует второй COM-сеанс.

Телеметрия `ApiDuoFarmer` оборачивает выбор цели и публикацию наблюдения. Бой,
поиск, ассист, хил, баффы и выход из застревания наследуются от прежнего алгоритма.
Отправка клавиши атаки означает только запрос атаки/сближения, а не установленный
факт движения. Повтор атаки не продлевает окно поиска камеры бесконечно.

Запуск и ограничения камеры: [VISION_QUICKSTART.md](VISION_QUICKSTART.md).
