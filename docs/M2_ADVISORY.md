# M2 — advisory mode (в разработке)

Первая итерация от 2026-09-28: интерфейс `LLMProvider`, адаптер локального
chat completions runtime, строгие Pydantic-контракты, prompt и GUI-панель.
Поддерживаются предложения `ask_user`, `rest`, `attack_target`. Это начальный
каталог рекомендаций, не библиотека исполнения M3. Неизвестные skills,
лишние поля, raw input, tool calls, обрезанные и невалидные ответы отклоняются.
Валидность схемы не доказывает правильность игрового решения.

В GUI укажите цель и нажмите «Запросить совет». Нужен WorldState не старше
секунды. Один запрос выполняется в daemon thread; повторный запрос во время
ожидания запрещён. Worker не использует Qt или ActionController. Панель
показывает исходный frame ID и явно помечает ответ как совет по прошлому снимку.
Результаты не исполняются. Закрытие GUI не ждёт ответа сервера; уже отправленный
запрос может завершиться на сервере после закрытия окна.

По умолчанию используется `http://127.0.0.1:8080` и модель
`Ternary-Bonsai-2-27B-PTQ1_0.gguf`. Сервер запускается отдельно.
Fallback Qwen подключается тем же адаптером через `--llm-url` и `--llm-model`:
нужно указать адрес локального runtime и его точный model ID. Автоматического
переключения или загрузки второй модели нет. Совместимость конкретного runtime
с `response_format: json_schema` требует проверки с запущенным сервером.

```powershell
.venv\Scripts\python.exe -m l2_agent
.venv\Scripts\python.exe scripts/benchmark_advisory.py --runs 3
```

Benchmark принимает `--state path/to/world-state.json`, `--goal`, `--url`,
`--model` и `--output`. Без state используется синтетический unknown WorldState:
это проверка контракта и осторожного ответа, не качества планирования в игре.
JSON-отчёт содержит каждый успешный/ошибочный запрос, latency и токены.
Tokens/s — completion tokens, делённые на полное время HTTP-запроса, включая
prefill; это не чистая скорость decode. Usage может отсутствовать.
`nvidia-smi` снимает общую занятую VRAM до/после серии, не пиковую память модели.
RAM сервера и пиковая VRAM пока не измеряются.

## Проверка и оставшиеся критерии

33 затронутых теста advisory/GUI/WorldState прошли. Ruff новых модулей прошёл.
На 2026-09-28 локальный endpoint отклонил соединение (WinError 10061).
Попытка benchmark сохранена в `artifacts/m2-benchmark-unavailable.json`;
это не результат производительности Bonsai. Реальная генерация, качество,
latency на GTX 1080 Ti, общий расход RAM/VRAM и fallback Qwen ещё не проверены.
Также требуется ручная проверка панели вместе с live preview.
M2 не закрыта; M3 не начата.
