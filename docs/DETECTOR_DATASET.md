# Кадры для детектора — M1

В GUI нажмите «Сохранить кадр для разметки через 3 секунды» и переключитесь
в выбранную игру. Preview должен быть включён. Сохраняется один свежий кадр
клиентской области без overlays; ручной тест ввода при планировании останавливается.
При потере фокуса, изменении геометрии или отсутствии свежего кадра сохранение отклоняется.

Каталог `datasets/detector/raw/<uuid>/` содержит исходный `image.png` и `sample.json`:
версию формата, SHA-256 изображения, UTC сохранения, номер и monotonic timestamp
кадра, размеры, окно, текущий WorldState и подтверждённый ROI, если он применим.
Значения WorldState являются гипотезами восприятия, а не эталонной разметкой.
Monotonic timestamp сравним только внутри текущего запуска.

Новые примеры имеют `annotation_status: unlabeled`, `objects: []`.
Пустой список не означает отсутствие объектов. После ручной проверки статус
меняется на `reviewed`; только тогда пустой список означает отрицательный пример.
Каждый объект содержит `kind` из [списка 23 классов](DETECTOR_CLASSES.md),
нормализованный `box` (`x1`, `y1`, `x2`, `y2`) и необязательный `selected`.
Контракт проверяет `DetectorSample` из `l2_agent.dataset`.

Собирайте разные сцены, дистанции, ракурсы и освещение, включая кадры без объектов.
Разделять train/validation следует по сценам или сессиям, чтобы соседние кадры
не завышали качество. Данные остаются локально и исключены из Git.
Для разметки нажмите «Разметить сохранённый кадр», откройте его `sample.json`,
выберите класс и обведите каждый объект. Можно указать, выбран ли объект целью;
если это неизвестно, оставьте соответствующее значение. Ошибочную рамку выберите
в списке и удалите, затем нарисуйте заново. Для смены класса без изменения рамки
выберите её в списке, новый класс и «Применить класс к выбранной рамке».
Перед сохранением подтвердите полноту
разметки. «Отмена» не меняет файл. SHA-256 и размеры изображения проверяются при
открытии и сохранении; метаданные заменяются через временный файл.
Первое шестиклассовое обучение описано в `DETECTOR_TRAINING.md`;
новая схема требует повторной проверки разметки и нового обучения.
Live inference детектора ещё не подключён.

## Экспорт для обучения

Создайте JSON файл групп сцен, например `datasets/detector/groups.json`:

```json
{
  "village-session-1": {"split": "train", "samples": ["<sample_id первого кадра>"]},
  "forest-session-2": {"split": "val", "samples": ["<sample_id второго кадра>"]}
}
```

Замените placeholders на 32-значные идентификаторы из имён каталогов кадров.
Каждое имя группы должно встречаться ровно один раз. Несколько кадров перечисляйте
внутри одного массива `samples`: `["id1", "id2", "id3"]`.
Повторяющиеся ключи теперь отклоняются с ошибкой, а не теряются при чтении JSON.
Все соседние и похожие кадры одной сцены включайте в одну группу; одна группа
целиком относится к train или val. Экспортёр не определяет похожие сцены сам.
Нужны обе выборки и хотя бы один размеченный объект в train.

```powershell
.\.venv\Scripts\python.exe -m l2_agent.dataset_export --groups datasets/detector/groups.json --output datasets/detector/export-v1
```

Экспортируются только явно перечисленные reviewed кадры. Непроверенный кадр,
повтор идентификатора, повреждённое изображение или одинаковый SHA-256 между
train/val отклоняют экспорт. Существующий каталог не перезаписывается.
Результат содержит `images`, `labels`, `dataset.yaml` и `export.json` с исходными
метаданными и группами. При ошибке записи может остаться незавершённый каталог:
его нельзя использовать; повторите экспорт в новый каталог.
`selected` сохраняется в отчёте; выбранный моб имеет отдельный класс `mob_selected`.
В export.json записывается taxonomy_version=2. Старые кадры схемы 1 нужно
повторно проверить и сохранить через редактор перед экспортом.

Формат строк: класс и нормализованные центр/ширина/высота рамки;
источник: [Ultralytics detection format](https://docs.ultralytics.com/datasets/detect/),
проверен 2026-09-26. Порядок классов фиксирован в `DETECTOR_CLASSES`.
Экспорт не устанавливает Ultralytics и не запускает обучение.
